# My Portfolio

Personal portfolio website built as the final project for **Introduction to Web Development**, the third course in the [Microsoft Full-Stack Developer Professional Certificate](https://www.coursera.org/professional-certificates/microsoft-full-stack-developer) on Coursera.

🔗 **Live demo:** https://kero-romany19.github.io/My_Portfolio/

## About

This is my personal portfolio site, built to practice core web development fundamentals and to have a place where I can showcase my projects, skills, and progress as I work toward becoming a Full-Stack Developer.

## Sections

- **About** — a short introduction about who I am and what I'm working on
- **Skills** — technologies and tools I'm currently learning and using
- **Projects** — a showcase of projects I've built
- **Contact** — ways to reach me

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

To run this project locally:

```bash
git clone https://github.com/kero-romany19/My_Portfolio.git
cd My_Portfolio
```

Then just open `index.html` in your browser — no build step or dependencies required.
